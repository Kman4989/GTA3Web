# GTA3Web
 webport of gta 3/gta iii by woahhcrackers

features ported mods and textures to make it more high quality and fixes that the old gta 3 port by shxyder/larpinguser had

## Running

Just open `index.html`. If you opened it straight from disk (`file://`), it asks you to select the game folder once (the folder that contains `index.html`, `re3.js`, `audio/`, `models/`, ...) and reads the assets locally, so no web server is needed. Chromium browsers remember the folder for next time; Firefox/Safari will ask again each launch. When hosted over http(s) it starts immediately.
